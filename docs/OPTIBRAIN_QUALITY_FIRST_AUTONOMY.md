## Architecture decision

Keep OptiBrain's existing event intake, AutomationStore run claims, immutable checkpoints, read observers, backup verification and guarded release. Add only a bounded dispatcher that ranks a small catalogue, checks dependencies, claims a run, calls a reviewed deterministic handler, independently checks its result and commits the checkpoint atomically. A separate approved registration can integrate the dispatcher with the existing wake-up infrastructure.
