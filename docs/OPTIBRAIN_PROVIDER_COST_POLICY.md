# Provider cost and retention policy

AUTHORITATIVE CURRENT. Fixed read operations, source age, last query, request count for the collection, cache hits, known/unknown cost class and exposed credits are recorded. A subscription is not treated as zero cost; unknown money/credits remain null. No units, API upgrade or paid enrichment purchase is authorized here.

Native daily Google collection has at most13 calls, two-MiB responses and40seconds total; HTTP failure cools down for a day while retaining dated prior evidence. No caller-supplied URL/query/upload/mutation is accepted. Bounded manual URL inspections/Keyword Planner checks are not automatically repeated. Existing Apollo workspace reads have zero enrichment credits; no mass discovery or enrichment. Reuse first-party native data instead of repeatedly pulling equivalent broker data. Clay can fill a verified missing field only when a callable connection exists; it never repeats adequate Apollo enrichment.

Own-site crawl: at most160 URLs, four concurrent, robots/delay respected, bounded same-host HTTPS redirects and one-MiB HTML. Competitor sample: ten discovered URLs, bounded primary read with eight-second timeout;403 remains unavailable rather than bypassed. Public records use official datasets and exact licence/access conditions. REQ noncommercial bulk data is not used commercially. No CAPTCHA/private-site bypass.

Raw snapshots have two-MiB/chunk limits. Each source/page retains at most12 snapshots within90days, with its latest proof retained for reconstruction. Facts referencing retired snapshots retire together; current aliases never silently merge. Immutable source-date daily variants retain provider corrections for730days. Old derived non-snapshot variants retire after365days while the latest entity/source fact remains. Raw contacts are root-only; private owner projection is capped at256KiB. Repeated input identity skips ingestion; no continuous full-history polling or provider retry storm.

Refresh frequencies in [source register](OPTIBRAIN_MARKETING_DATA_SOURCES.md) are distinct from successful observations. Manual sources do not become freshly fetched merely because the view renders. Stale evidence is labeled; provider health fails independently. Disk growth remains subject to the existing root-state backup/retention policy; protected and immutable business/effect evidence is never purged as a market-cache cleanup.
