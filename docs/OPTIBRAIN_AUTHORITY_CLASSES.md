# Optimization authority classes

AUTHORITATIVE CURRENT. These classes classify future work; they **do not activate permissions**. Provider OAuth capability never equals OptiBrain authority. Existing [scope](OPTIBRAIN_REAL_AUTOMATION_SCOPE.md), [communications](OPTIBRAIN_CUSTOMER_COMMUNICATION_CONTRACT.md), central action admission, root policy, expiry, protected-record checks and off-host effect fencing remain authoritative.

| Class | Intended work | Preparation versus execution |
|---|---|---|
| A — safe maintenance | Bounded data refresh, deterministic health checks, rebuildable metadata/cache repair | Automatic only within an existing allowlisted, budgeted scope. Evidence/authority/financial/provider business writes are not maintenance. |
| B — automatic preparation | Website branch/preview, article/image draft, supported Form draft/mapping, Ads draft, CRM-field proposal, Holo-ready brief | Authorized preparation may be autonomous. A draft in a provider account is still a provider write requiring an existing allowed adapter/scope. No publication, sequence enrollment or form switch follows automatically. |
| C — owner approval for production | Website publication, important image replacement, production Form switch, CRM schema, material GBP information, campaign activation or a new outreach family | Exact revision/targets/preview/tests/measurement/rollback are reviewed first. Approval then passes the independent current runtime safety/authority gate. |
| D — human-controlled/high consequence | Financial writes, major budgets, legal/contract commitments, important destruction | Separate explicit human authority and domain controls. Books READ is allowed; writes remain unauthorized in this mission. |

Higher consequence dominates mixed proposals; split independent changes when needed. Unknown classification defaults to BLOCKED for execution. No broad 'all permissions' request, generic APPROVED flag or hidden Form value can establish authority.

Public proposals/previews and service-writable research state are untrusted for provider execution. Existing authenticated human approval must bind exact payload/target/revision/expiry. Protected ownership always wins over TEST markers. Suppression, collisions, frequency limits and Apollo ownership remain absolute future-outreach constraints.

Normal deployment preserves existing authorized internal/customer scopes, cutoff, expiry, claim/effect history and kill switches. Fresh recovery applies the explicit writers-OFF policy in the [recovery contract](OPTIBRAIN_RECOVERY_AUTHORITY_CONTRACT.md); restored capability, destination configuration and proposal approval alone cannot reauthorize anything. Reconfirm authority through the established root process, never by editing a proposal.
