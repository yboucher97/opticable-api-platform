Opticable Business Autopilot V1 — internal, zero incremental cost

This worker produces original bilingual finished draft artifacts using the current
native source snapshots and a reviewed content bank. No model/provider client,
publishing adapter, financial action or application deployment is present.

It reuses the existing platform-intelligence timer, acquisition CONTENT_ASSET
records, append-only provenance and local automation storage. The only integration
is one ExecStartPost on the existing collection service, as the existing unprivileged
API account and collector interpreter. The isolated child uses system Python with
only standard-library code. No new scheduler, token cache, cloud repository or database is added.
The child inherits the existing Linux Landlock/seccomp development boundary;
network/ptrace/mount are denied, writes restricted to artifact scratch, CPU12s,
memory384MiB, file8MiB, parent timeout45s. Environment credentials are removed.
Global flock, daily/evidence receipts, content-addressed immutable revisions and
existing store IDs deduplicate work. A failed attempt records service failure;
it never authorizes a compensating business action. Source freshness is retained.
Future days receive updated analysis from the collector; the limited reviewed
content bank supplies reusable drafts, not an unrestricted generative agent.
Weekly calendars/plans and explicitly partial monthly reviews use the same run.

Permanent owner policy: every new expense (including paid model/image/API usage)
requires explicit approval. Public website edits, ads changes, sends and publication
require approval of the exact finished proposal. Existing credentials are never a
grant. New drafts/local organization/testing require no repetitive owner approval.
All 45 consequential flags and existing website approval controls remain intact.
The review JSON is a proposal, never a standing grant or production executor.

Tests: python3 -m unittest discover -s ops/business_autopilot -p 'test_*.py' -v
Full API: python -I -B ops/phase6/validate.py --suite full
Browser checks reuse the first-hosted-preview local traffic isolation model with
real Chromium/axe. Production-mode output is built on disk only; never deployed.
Authenticated localhost fixture expires after24h; no public route or Access edit.
Native sanitizer reused; customer forms, external links/scripts and analytics are
removed in preview. Original source/production build retains existing behavior.

Reviewed runtime: engine.py, runner.py, content_bank.json and the unchanged
workflow/automation/development_sandbox.py copied as sandbox.py. Each root-owned,
read-only, SHA256-listed. Manifest/directory ownership is checked before execution.
Install only this artifact-only runtime and business-artifacts.conf; application
and recovery PRs remain unmerged. Installation checkpoint records absence and
systemd preimage. Rollback removes only the dropin, daemon-reloads, then removes
only exact matching installed runtime files. Keep all artifacts, DB facts and
source history. Do not restore an older database or restart the API.

Content classification: campaign / service / language / channel / DRAFT / revision.
Existing files are never moved/deleted. A verified dedicated Opticable cloud root
was not found; an unrelated company folder is deliberately left untouched.

Initiative learning records preserve evidence, artifact stage, pending exact
approval, deployment=false and unknown outcome. No improvement is reported as
successful in business terms until approved release and measured outcome exist.
